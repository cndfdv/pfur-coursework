Лабораторная работа 2. Реализация кэш на Python
 ⁃ Создать класс Cache
 ⁃ Реализовать базовые методы set(k,v,ttl - необязательный параметр), get(k)v, delete(k)v
 ⁃ Ключ не должен быть null
 ⁃ Для реализации функции времени жизни ключа в кэше использовать поток, который следит за истечением времени хранения ключа в кэше
 ⁃ Все методы кэша должны быть потокобезопасны
 ⁃ Добавить метод  computeIfPresent(k, func(v)newV), который работает следующим образом: если в кэше есть ключ  K, то вызывается функция f(v)newV, аргументом которой является текущее значение под ключом, а возвращаемое значение - новое значение. Метод должен быть потокобезопасным
 ⁃ Для проверки потокобезопасности computeIfPresent написать скрипт, в котором в трех потоках в цикле из 1000 итераций вызывается данный метод, а в функции производится инкремент значения. В конце работы скрипта счетчик (значение под ключом) должно быть равно 3000.
