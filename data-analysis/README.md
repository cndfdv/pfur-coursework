# Анализ данных — ПФУР

Материалы курса по анализу данных: контрольные работы по набору Titanic, практика во втором семестре и проект `nosql_porj`.

## Содержание

- `kr_1/` — ноутбуки контрольной работы № 1 и файл `Titanic.csv`;
- `sem_2/lection_2_practice.ipynb` — практическая работа;
- `nosql_porj/` — проект поиска научных публикаций с backend, frontend, Docker Compose и документацией;
- `trash.ipynb` — отдельный ноутбук.

## Запуск

Откройте нужный ноутбук в Jupyter и выполняйте его ячейки по порядку. Для запуска проекта `nosql_porj` используйте его собственные инструкции в [README проекта](nosql_porj/README.md).
