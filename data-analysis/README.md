# Анализ данных — ПФУР

Учебный репозиторий по анализу данных. Сейчас в нём находится ноутбук с решением задачи по обработке табличных данных и SQL-подобным анализом активности игроков.

## Содержание

- `trash.ipynb` — рабочий Jupyter Notebook с задачей и решением.

## Запуск

Откройте `trash.ipynb` в JupyterLab или Google Colab и выполните ячейки по порядку. Репозиторий предназначен для учебных экспериментов и будет дополняться новыми работами.
