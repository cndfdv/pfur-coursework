# ИИ в лингвистике

Учебный проект с исходными заданиями курса и решениями первых трёх пунктов лабораторной работы № 1. Ноутбук показывает применение регулярных выражений для поиска автомобильных номеров, очистки HTML и сборки предложения из токенов.

**Решение:** [лабораторная работа № 1](lab_1/main.ipynb). **Задания курса:** [исходный ноутбук](Примеры_кода_для_практических_заданий.ipynb).

## Структура

```text
.
├── .gitignore
├── README.md
├── requirements.txt                            # окружение Jupyter
├── Примеры_кода_для_практических_заданий.ipynb  # задания всего курса
└── lab_1/
    ├── main.ipynb                               # решения пунктов 1.1–1.3
    └── data/
        ├── moviescripts.html
        ├── pokupka_avtomobilya_regex.docx
        └── Ода дорожному потоку.docx
```

## Выполненные пункты

| Пункт | Задание | Результат |
| --- | --- | --- |
| 1.1 | Поиск автомобильных номеров | Вывод всех найденных номеров и их количества для каждого DOCX. В документе о покупке автомобиля найдено 25 вхождений, в «Оде дорожному потоку» — 17. Повторения учитываются. |
| 1.2 | Удаление HTML-тегов | Очистка `moviescripts.html` из задания и вывод примеров на тексте DOCX, обёрнутом в HTML-теги. |
| 1.3 | Сборка предложения | Сборка предложения из токенов одним вызовом `re.sub`. |

Регулярные выражения в пункте 1.1 проверяют формат записи номера, а не наличие номера или региона в реестре. Исходный пример задания использует заглавные кириллические буквы `АВЕКМНОРСТУХ`. Поиск в DOCX также принимает похожие латинские буквы, смешанные записи и нижний регистр. Для прицепов добавлен формат «две буквы, четыре цифры, регион», например `АА676767`. Найденные записи выводятся в исходном виде. Файлы DOCX не являются HTML: для примеров пункта 1.2 текст их абзацев оборачивается в HTML-теги.

Очистка HTML в пункте 1.2 рассчитана на файл задания и примеры в ноутбуке.

В каждом пункте после решения и тестов задания идёт работа с локальными файлами. Тексты DOCX читаются в пункте 1.1 и затем используются в пунктах 1.2 и 1.3.

## Установка и запуск

Из корня проекта выполните:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd lab_1
jupyter lab
```

В JupyterLab откройте `main.ipynb` и выполните ячейки сверху вниз. Пути к данным заданы относительно `lab_1`. Для чтения DOCX используется `python-docx`, для остальных заданий — стандартная библиотека Python. Для воспроизведения проверки на HTML используется локальный файл `lab_1/data/moviescripts.html`: исходный файл [moviescripts.html](https://www.dropbox.com/s/dqp8yjmtu23fblj/moviescripts.html?dl=1) был скачан 08.10.2026. Выполнение ячеек не требует обращения к сети.

Ноутбук можно также открыть в интерфейсе GitHub по пути [`lab_1/main.ipynb`](lab_1/main.ipynb); сохранённые в нём выводы доступны в просмотре ноутбука.

### Автоматическая проверка

Все кодовые ячейки выполнены последовательно из `lab_1`. В ноутбуке оставлены только проверки через `assert` из исходного задания; результаты на DOCX выводятся как примеры.

Из каталога `lab_1` команда ниже исполняет ноутбук и сохраняет проверенную копию вне проекта:

```sh
mkdir -p /tmp/ai-in-linguist-check
python -m jupyter nbconvert --to notebook --execute main.ipynb --output main.checked --output-dir /tmp/ai-in-linguist-check --ExecutePreprocessor.timeout=60
```
