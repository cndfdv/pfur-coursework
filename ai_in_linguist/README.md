| --- | --- | --- |
| 1 | Регулярные выражения: пункты 1.1–1.3 | [lab_1/main.ipynb](lab_1/main.ipynb) |
| 2 | Токенизация, n-граммы, TF-IDF и классификация | [lab_2/main.ipynb](lab_2/main.ipynb) |
| 3 | Коррекция опечаток и сравнение слов | [lab_3/main.ipynb](lab_3/main.ipynb) |

Исходные примеры курса: [Примеры_кода_для_практических_заданий.ipynb](Примеры_кода_для_практических_заданий.ipynb).

## Запуск

Из корня проекта:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd lab_2
jupyter lab
```

Откройте `main.ipynb` и выполните все ячейки сверху вниз. Для другой работы замените `lab_2` на `lab_1` или `lab_3`. В редакторе с поддержкой ноутбуков выберите Python из `.venv` проекта. Проверено с Python 3.12.

Все входные данные лежат локально, во время выполнения ячеек интернет не нужен. Третья работа читает архив из `../lab_2/data/news_science.zip`, поэтому структура папок должна сохраняться. Выводы сохранены в ноутбуках и доступны при просмотре на GitHub.

Для выполнения из командной строки, например для второй работы:

```sh
cd lab_2
mkdir -p /tmp/ai-in-linguist-check
python -m jupyter nbconvert --to notebook --execute main.ipynb --output lab_2.checked --output-dir /tmp/ai-in-linguist-check --ExecutePreprocessor.timeout=120
```

## Лабораторная 1

Поиск номеров, удаление HTML-тегов и сборка предложения из токенов. В примерах DOCX находятся 25 номеров в документе о покупке и 17 в «Оде дорожному потоку», включая повторения. Поиск принимает похожие латинские буквы, смешанный алфавит, нижний регистр и формат прицепа. Это проверка формы записи, а не проверка номера по реестру.

## Лабораторная 2

1. Отдельные облака слов для новостей и научных текстов без стоп-слов. К списку NLTK добавлены «это» и несколько форм «который».
2. Топ-20 биграмм и триграмм каждого жанра. Соседние документы не склеиваются.
3. По десять ключевых слов TF-IDF для двух новостей.
4. Сравнение слов и частей слов BPE с одинаковым классификатором `LogisticRegression`.

В сравнении используется одно стратифицированное разбиение: 96 текстов для обучения и 32 для проверки, `random_state=42`. BPE и оба TF-IDF обучаются только на обучающей части. TF-IDF для ключевых слов считается отдельно от эксперимента классификации.

Сравнение выводит accuracy, macro-F1, число признаков и матрицы ошибок для обоих
токенизаторов. Результаты относятся к одному учебному разбиению небольшого корпуса.

В исходных научных текстах встречаются технические вставки вроде «формула». Они учитываются при подсчёте n-грамм вместе с остальным текстом.

## Лабораторная 3

1. Сравнение `difflib`, RapidFuzz и SymSpell на трёх фразах из задания. Общий словарь — до 10 000 самых частых слов того же корпуса. Подготовка словаря не входит в замеры; показано среднее время трёх повторений на одном наборе слов.
2. Собственная функция полного расстояния Дамерау — Левенштейна: вставка, удаление, замена и перестановка. Рядом показаны библиотечные значения и время выполнения.
3. Замена одной буквы на соседнюю клавишу русской раскладки. Случайность фиксируется через `random.seed(42)`.
4. Буквенные частоты через `CountVectorizer(analyzer='char')` и косинусное сходство. На примере «кот» и «ток» видно, что порядок букв не учитывается.

Исправление опечаток выполняется по ограниченному словарю без контекста, поэтому отдельные предложения могут исправляться неверно. Время зависит от компьютера и не является оценкой качества исправлений.
