# Визуализация данных — лабораторные работы ПФУР

Коллекция учебных работ по визуализации и исследовательскому анализу данных.

## Структура

- `lab_1` — `lab_7` — ноутбуки; рядом с некоторыми работами находятся исходные данные и PDF-экспорты;
- `teor/` — теоретические материалы курса.

Работы охватывают анализ котировок, исследование наборов UCI, статистику текстов и визуализацию данных.

## Запуск

Откройте нужный файл `lab_*/...ipynb` в JupyterLab или Google Colab и выполните ячейки по порядку. Данные для соответствующих лабораторных лежат рядом с ноутбуками.
