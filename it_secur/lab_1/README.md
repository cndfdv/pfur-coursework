## Теория

В работе используется русский алфавит из 33 букв с нумерацией от 0 до 32. Буква `ё` учитывается отдельно. Операция `mod 33` возвращает результат в диапазон 0–32 и обеспечивает циклический переход через конец алфавита.

Для шифра Цезаря каждая буква с кодом `x` сдвигается на один и тот же числовой ключ `k`:

- шифрование: `y = (x + k) mod 33`;
- расшифрование: `x = (y - k) mod 33`.

В шифре Виженера ключ является словом. Его буквы циклически повторяются до длины текста. Поэтому для каждой позиции используется свой сдвиг `k_i`:

- шифрование: `y_i = (x_i + k_i) mod 33`;
- расшифрование: `x_i = (y_i - k_i) mod 33`.

## Что сделано

Книга содержит пять листов:

1. `Алфавит` — номера 0–32, буквы русского алфавита и повторная нумерация.
2. `1 Цезарь шифр` — слово `криптография`, выбранный ключ 8, результат `тшрчъцкшзьрж`.
3. `2 Цезарь расшифр` — вариант 8, ключ 23, криптограмма `зящдцв`, результат `сигнал`.
4. `3 Виженер шифр` — слово `криптография`, ключ `код`, результат `хямъбтнядячг`.
5. `4 Виженер расшифр` — вариант 8, ключ `вой`, криптограмма `фухжртёучку`, результат `телевидение`.

## Что происходит в Excel

- `VLOOKUP` (`ВПР` в русской версии Excel) переводит букву в числовой код и код обратно в букву.
- Абсолютные ссылки вида `$B$5` удерживают ячейку с ключом при копировании формул вправо.
- `MOD(...,33)` (`ОСТАТ` в русской версии Excel) выполняет циклический переход по алфавиту.
- В заданиях Виженера функции `MID`, `MOD`, `COLUMN` и `LEN` автоматически повторяют ключ по всей длине слова.
- В книге используется обычный вид Excel без цветного оформления, заливок и декоративных рамок. Стандартная сетка включена на всех листах.
