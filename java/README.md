# Java — лабораторная работа №3 ПФУР

Maven-проект с реализациями базовых структур данных и алгоритмов на Java.

## Содержание

- `lab_3-main/src/main/java/lab3/queue/` — очередь;
- `lab_3-main/src/main/java/lab3/stack/` — стек;
- `lab_3-main/src/main/java/lab3/sort/` — сортировка;
- `lab_3-main/src/test/` — модульные тесты.

## Требования

- JDK 23 (в `pom.xml` заданы `maven.compiler.source` и `maven.compiler.target` со значением `23`);
- Maven; минимальная версия в проекте не зафиксирована.

## Проверка

```bash
cd lab_3-main
mvn test
```

Проект можно открыть в IntelliJ IDEA как Maven-проект.
