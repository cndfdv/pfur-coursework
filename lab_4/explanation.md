# Лабораторная работа №4

## Теория

Глубокая сеть прямого распространения состоит из последовательности полносвязных слоев. Каждый слой выполняет линейное преобразование, затем применяется нелинейная функция активации. Нелинейность нужна, чтобы сеть могла аппроксимировать сложные зависимости, а не только линейные границы.

Для бинарной классификации выход интерпретируется как вероятность одного из двух классов. Для многоклассовой классификации используется несколько выходов, и выбирается класс с максимальным логитом. Для регрессии сеть возвращает вещественное число, а качество удобно измерять MSE и MAE.

## Что сделано

Весь код написан на PyTorch.

Вариант 13:

- этап 1, IMDB: `3` скрытых слоя `16-32-16`, активации `relu-relu-tanh`, функция потерь MSE;
- сравнение с базовым классификатором `16-16`, `relu-relu`, бинарная кросс-энтропия;
- этап 2, многоклассовая классификация: `32-64-64`, `tanh-mish-relu`, CrossEntropy;
- этап 3, регрессия: `32-64-64`, `tanh-mish-relu`, MSE, проверка по `K=4` блокам.

Для IMDB используется локальный архив `IMDB/IMDB/aclImdb.zip`. Тексты переводятся в вектор признаков через `CountVectorizer`, после чего обучается PyTorch MLP.

Для второго и третьего этапов использованы локально доступные наборы из `sklearn.datasets`, чтобы лабораторная запускалась без лишних внешних зависимостей. По смыслу они закрывают те же типы задач: многоклассовую классификацию и регрессию.
