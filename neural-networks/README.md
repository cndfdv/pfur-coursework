# Нейронные сети — лабораторные работы РУДН

Учебный репозиторий с лабораторными работами по нейронным сетям, ноутбуками, отчётами и сгенерированными иллюстрациями.

## Структура

- `lab_1` — `lab_6/` — отдельные лабораторные;
- `main.ipynb` в каждом каталоге — исходный ноутбук;
- `explanation.md` и `comments.md` — пояснения к работе;
- `report_lab*.pdf` — готовые отчёты;
- `run_lab.py` — запуск выбранного ноутбука с сохранением графиков в `figures/`.

## Запуск лабораторной

```bash
python run_lab.py 3
```

Команда запускает `lab_3/main.ipynb` как Python-код и сохраняет графики в `lab_3/figures/`. Для интерактивного исследования проще открыть соответствующий notebook в JupyterLab.
