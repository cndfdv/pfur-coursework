## Общая идея лабораторной

В этой лабораторной изучаются нейронные сети для последовательностей.

Последовательность — это данные, где важен порядок элементов.

Примеры:

- текст: порядок слов влияет на смысл;
- временной ряд температуры: порядок измерений важен для прогноза;
- звук: сигнал идет во времени;
- финансовый ряд: текущее значение зависит от прошлых.

Обычная полносвязная сеть не имеет памяти. Она получает фиксированный набор признаков и выдает ответ.

Рекуррентная сеть обрабатывает данные по шагам и хранит внутреннее состояние, то есть память о предыдущих шагах.

## Что такое RNN

RNN — recurrent neural network, рекуррентная нейронная сеть.

На каждом шаге она получает:

- текущий вход `x_t`;
- скрытое состояние с прошлого шага `h_(t-1)`.

Затем вычисляет новое скрытое состояние:

```text
h_t = f(x_t, h_(t-1))
```

Скрытое состояние — это память сети. В нем хранится информация о том, что сеть уже видела раньше.

Для текста это может быть информация о предыдущих словах.

Для температуры — информация о прошлых измерениях.

## Проблема обычной RNN

Обычная RNN плохо хранит длинные зависимости.

Например, в длинном отзыве важное слово может быть в начале, а итоговый смысл понятен только в конце.

При обучении обычной RNN градиенты проходят через много временных шагов. Они могут:

- исчезать, становиться почти нулевыми;
- взрываться, становиться слишком большими.

Из-за этого обычной RNN трудно запоминать дальний контекст.

## Что такое LSTM

LSTM — long short-term memory.

Это рекуррентная сеть с более сложной внутренней структурой. Она специально придумана, чтобы лучше хранить долгосрочную информацию.

Главная идея LSTM: у нее есть не только скрытое состояние `h_t`, но и состояние ячейки `c_t`.

Состояние ячейки можно представить как долгую память.

LSTM управляет этой памятью через ворота:

- forget gate — решает, что забыть;
- input gate — решает, что записать;
- output gate — решает, что выдать наружу.

Ворота — это маленькие нейронные слои с сигмоидой. Они дают значения от `0` до `1`.

Если значение близко к `0`, информация почти не проходит.

Если близко к `1`, информация проходит почти полностью.

Поэтому LSTM может научиться хранить важные признаки долго и забывать ненужные.

## Что такое двунаправленная LSTM

Обычная LSTM читает последовательность слева направо:

```text
слово 1 -> слово 2 -> слово 3 -> ...
```

Двунаправленная LSTM читает последовательность в двух направлениях:

```text
слева направо
справа налево
```

Потом признаки из двух направлений объединяются.

Для текста это полезно, потому что смысл слова часто зависит не только от предыдущих слов, но и от следующих.

Например:

```text
not bad
```

Если смотреть только на слово `not`, смысл непонятен. Если видеть следующее слово `bad`, становится понятно, что фраза скорее положительная.

В PyTorch двунаправленность задается так:

```python
bidirectional=True
```

## Словарь

Нейросеть не работает со словами напрямую. Поэтому каждому слову присваивается номер.

В коде:

```python
vocab = {"<pad>": 0, "<unk>": 1}
```

Специальные токены:

- `<pad>` — заполнение коротких последовательностей нулями;
- `<unk>` — неизвестное слово.

Дальше берутся самые частые слова:

```python
for word, _ in counter.most_common(max_words - 2):
    vocab[word] = len(vocab)
```

Например:

```text
"movie" -> 15
"good" -> 38
"bad" -> 42
```

После этого отзыв превращается в последовательность чисел.

## Padding

Отзывы имеют разную длину. Один отзыв может содержать 40 слов, другой 300 слов.

Но в одном batch тензоры должны иметь одинаковую длину.

Для этого используется padding:

```python
pad_sequence(texts, batch_first=True, padding_value=0)
```

Короткие последовательности дополняются нулями.

Ноль соответствует `<pad>`.

## Embedding

Embedding — это слой, который превращает номер слова в плотный вектор.

В коде:

```python
self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
```

Для варианта 13:

```text
embed_dim = 64
```

Это значит, что каждое слово представляется вектором из 64 чисел.

Например:

```text
"good" -> [0.12, -0.03, 0.44, ..., 0.08]
```

Embedding обучается вместе с моделью. Сеть сама подбирает такие векторы слов, которые полезны для классификации отзывов.

## Модель BiLSTM по варианту

В коде:

```python
self.rnn = nn.LSTM(
    input_size=embed_dim,
    hidden_size=32,
    num_layers=2,
    batch_first=True,
    bidirectional=True,
    dropout=0.2,
)
```

Разбор:

- `input_size=64` — размер embedding-вектора каждого слова;
- `hidden_size=32` — в каждом направлении 32 нейрона;
- `num_layers=2` — два LSTM-слоя;
- `bidirectional=True` — сеть двунаправленная;
- `dropout=0.2` — регуляризация между слоями;
- `batch_first=True` — форма входа `(batch, sequence, features)`.

Так как сеть двунаправленная, выход последнего состояния имеет две части:

- прямое направление;
- обратное направление.

В коде они объединяются:

```python
last_forward = hidden[-2]
last_backward = hidden[-1]
torch.cat([last_forward, last_backward], dim=1)
```

Каждая часть имеет размер 32. Вместе получается 64 признака.

Затем идет выходной слой:

```python
self.output = nn.Linear(64, 1)
```

Он выдает один логит для бинарной классификации.

## Функция потерь IMDB

Используется:

```python
nn.BCEWithLogitsLoss()
```

Она подходит для бинарной классификации.

Важно: модель выдает логит, а не вероятность. Поэтому `Sigmoid` не добавляется в модель.

Для подсчета accuracy применяется:

```python
torch.sigmoid(logits) >= 0.5
```

## Сравнение с Conv1D

По заданию нужно сравнить рекуррентную сеть с одномерной сверточной сетью.

Conv1D для текста работает не по символам, а по последовательности embedding-векторов.

Идея такая:

- фильтр смотрит на несколько соседних слов;
- ищет локальные фразы и шаблоны;
- например: `not good`, `very bad`, `excellent movie`.

В коде:

```python
nn.Conv1d(embed_dim, 64, kernel_size=5, padding=2)
```

Фильтр размера 5 смотрит на окно из 5 токенов.

Сеть содержит три сверточных слоя:

```python
Conv1d -> ReLU -> MaxPool1d
Conv1d -> ReLU -> MaxPool1d
Conv1d -> ReLU -> AdaptiveMaxPool1d
```

Conv1D обычно быстрее LSTM, потому что свертки можно считать параллельно.

Но LSTM лучше учитывает порядок и дальние зависимости.

## Подготовка временного ряда

Из таблицы убирается столбец даты:

```python
feature_frame = jena.drop(columns=["Date Time"])
```

Остальные числовые признаки нормализуются:

```python
mean = raw_values[:train_border].mean(axis=0)
std = raw_values[:train_border].std(axis=0)
values = (raw_values - mean) / std
```

Среднее и стандартное отклонение считаются только по обучающей части. Это правильно, потому что тестовые данные нельзя использовать при подготовке обучения.

## Что означают LOOKBACK, DELAY и STEP

В коде:

```python
LOOKBACK = 1440
DELAY = 144
STEP = 6
```

Данные Jena Climate измерялись каждые 10 минут.

`LOOKBACK = 1440` означает 1440 измерений назад:

```text
1440 * 10 минут = 14400 минут = 10 дней
```

`DELAY = 144` означает прогноз на 144 измерения вперед:

```text
144 * 10 минут = 1440 минут = 1 день
```

`STEP = 6` означает брать одно значение в час:

```text
6 * 10 минут = 60 минут
```

То есть для каждого примера сеть получает 10 дней истории с шагом 1 час и должна предсказать температуру через 1 день.

## Модель Jena Climate по варианту

В коде:

```python
self.rnn = nn.LSTM(
    input_size,
    64,
    num_layers=3,
    batch_first=True,
    bidirectional=True,
    dropout=0.3,
)
```

Разбор:

- `input_size` — количество погодных признаков в один момент времени;
- `64` — число нейронов в каждом направлении;
- `num_layers=3` — три LSTM-слоя;
- `bidirectional=True` — двунаправленная LSTM;
- `dropout=0.3` — прореживание по варианту.

Так как LSTM двунаправленная, итоговый вектор имеет размер:

```text
64 + 64 = 128
```

Выходной слой:

```python
self.output = nn.Linear(128, 1)
```

Он предсказывает одно число — температуру.

## Почему для Jena используется регрессия

В IMDB модель выбирает класс: отрицательный или положительный отзыв.

В Jena Climate модель предсказывает число: температуру.

Это регрессия.

Функция потерь:

```python
nn.MSELoss()
```

Дополнительно считается MAE:

```python
torch.abs(pred - y).sum()
```

MAE показывает среднюю ошибку в градусах.

## Сравнение Conv1D + LSTM

По заданию нужно сравнить основную рекуррентную сеть с моделью, где сначала идет одномерная сверточная часть.

В коде:

```python
self.conv = nn.Sequential(
    nn.Conv1d(input_size, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv1d(32, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv1d(32, 32, kernel_size=3, padding=1),
    nn.ReLU(),
)
```

Conv1D здесь ищет локальные временные закономерности:

- резкий рост температуры;
- короткие колебания;
- локальные шаблоны давления, влажности и температуры.

После сверточного блока признаки передаются в LSTM:

```python
self.rnn = nn.LSTM(32, 64, num_layers=3, batch_first=True, bidirectional=True, dropout=0.3)
```

Идея такой модели:

1. Conv1D быстро выделяет локальные признаки.
2. LSTM учитывает порядок и более длинные зависимости.

## Что делает цикл обучения

Для классификации IMDB:

1. Берется batch текстов.
2. Слова переводятся в embedding.
3. Последовательность проходит через LSTM или Conv1D.
4. Модель выдает логит.
5. `BCEWithLogitsLoss` считает ошибку.
6. `loss.backward()` считает градиенты.
7. `optimizer.step()` обновляет веса.

Для Jena Climate:

1. Берется batch временных окон.
2. Каждое окно содержит историю за 10 дней с шагом 1 час.
3. Модель предсказывает температуру через 1 день.
4. MSE считает ошибку прогноза.
5. MAE показывает среднюю ошибку в градусах.

## Что важно уметь объяснить на защите

1. RNN обрабатывает последовательность по шагам и хранит скрытое состояние.

2. LSTM лучше обычной RNN, потому что имеет ворота и состояние ячейки для долгой памяти.

3. Двунаправленная LSTM читает последовательность в двух направлениях.

4. Embedding превращает номер слова в обучаемый числовой вектор.

5. Padding нужен, чтобы тексты разной длины можно было объединять в один batch.

6. Для IMDB используется бинарная классификация и `BCEWithLogitsLoss`.

7. Conv1D для текста ищет локальные шаблоны слов.

8. Jena Climate — задача регрессии, потому что предсказывается температура.

9. `LOOKBACK=1440`, `DELAY=144`, `STEP=6` соответствуют 10 дням истории, прогнозу на 1 день вперед и одному значению в час.

10. Conv1D + LSTM объединяет локальное выделение признаков и рекуррентную обработку последовательности.

## Вывод

В лабораторной работе были рассмотрены глубокие модели для последовательностей: LSTM, двунаправленная LSTM, Conv1D для текста и комбинация Conv1D с LSTM для временных рядов.

На этапе IMDB была построена двунаправленная LSTM-сеть варианта 13. Текстовые отзывы сначала токенизируются, затем слова переводятся в индексы, индексы проходят через embedding-слой, а затем последовательность обрабатывается LSTM. Двунаправленность позволяет учитывать контекст как слева направо, так и справа налево. Это важно для текста, потому что смысл слова часто зависит от соседних слов с обеих сторон.

Для сравнения была построена Conv1D-модель. Она работает быстрее рекуррентной сети и ищет локальные шаблоны слов, например короткие устойчивые фразы. Сравнение BiLSTM и Conv1D показывает два разных подхода к анализу текста: рекуррентная модель лучше отражает последовательную природу данных, а сверточная модель быстрее выделяет локальные признаки.

На этапе Jena Climate была решена задача прогноза температуры. Из временного ряда формируются окна: 10 дней истории с шагом 1 час используются для прогноза температуры через 1 день. Основная модель — трехслойная двунаправленная LSTM с dropout `0.3`. Для сравнения используется модель Conv1D+LSTM, где сверточный блок сначала выделяет локальные временные признаки, а LSTM затем обрабатывает последовательность этих признаков.

Итог: LSTM подходит для последовательностей, где важен порядок и долговременная зависимость. Conv1D полезна для поиска локальных шаблонов. Комбинация Conv1D и LSTM объединяет оба подхода: локальное выделение признаков и рекуррентную память.
