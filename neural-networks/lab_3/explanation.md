# Лабораторная работа №3

Тема: сети Элмана, Хопфилда и Хэмминга.

Вариант 13:

- динамический сигнал: `g(k)=sin(2k^2-6k+3)`;
- интервал для `g(k)`: `[-0.02, 2.36]`;
- шаг дискретизации: `0.025`;
- повторы основного сигнала: `R=[2,5,6]`;
- статические образы: цифры `0`, `1`, `4` размером `12x10`.

## Общая идея лабораторной

В этой работе рассматриваются три разные нейросетевые идеи.

Сеть Элмана используется для распознавания динамического образа, то есть последовательности. Здесь важны не только сами числа, но и порядок, в котором они идут.

Сеть Хопфилда используется как ассоциативная память. Она хранит несколько эталонных бинарных образов и может восстанавливать правильный образ из зашумленного входа.

Сеть Хэмминга тоже распознает статические бинарные образы, но работает через сравнение входа с эталонами. Она выбирает тот эталон, который ближе всего к входному образу по количеству совпадающих пикселей.

## Что такое динамический образ

Динамический образ — это сигнал во времени. В этой лабораторной вход сети — не одна точка, а длинная последовательность чисел.

Есть два типа участков:

- основной сигнал `p1(k)=sin(4*pi*k)`;
- сигнал, который нужно распознать, `p2(k)=g(k)=sin(2k^2-6k+3)`.

Для основного сигнала целевой ответ равен `-1`.

Для распознаваемого сигнала целевой ответ равен `1`.

То есть сеть должна на каждом шаге последовательности сказать: сейчас идет обычный фоновый сигнал или нужный фрагмент.

Обучающая последовательность строится так:

```python
P = [p1, p1, p2, p1, p1, p1, p1, p1, p2, p1, ..., p2]
```

Вариант `R=[2,5,6]` означает:

- сначала основной сигнал повторяется 2 раза, затем идет `p2`;
- затем основной сигнал повторяется 5 раз, затем идет `p2`;
- затем основной сигнал повторяется 6 раз, затем идет `p2`.

Так сеть видит не один короткий пример, а длинную временную последовательность с несколькими появлениями нужного образа.

## Сеть Элмана

Сеть Элмана — это рекуррентная нейронная сеть. Главное отличие рекуррентной сети от обычной полносвязной сети в том, что она имеет память о предыдущих шагах.

Обычная сеть получает вход `x` и сразу выдает ответ:

```text
x -> сеть -> y
```

Рекуррентная сеть на каждом шаге получает:

- текущий вход `x_t`;
- скрытое состояние с прошлого шага `h_(t-1)`.

Схема такая:

```text
x_t + h_(t-1) -> RNN -> h_t -> output
```

Скрытое состояние `h_t` — это внутренняя память сети. В нем сеть хранит информацию о том, что происходило раньше в последовательности.

В лабораторной сеть Элмана реализована через `torch.nn.RNN`:

```python
self.rnn = nn.RNN(
    input_size=1,
    hidden_size=8,
    nonlinearity="tanh",
    batch_first=True,
)
```

Что это значит:

- `input_size=1` — на каждом шаге во вход подается одно число сигнала;
- `hidden_size=8` — внутри рекуррентного слоя 8 нейронов;
- `nonlinearity="tanh"` — используется гиперболический тангенс;
- `batch_first=True` — форма входа задается как `(batch, time, features)`.

После рекуррентного слоя стоит линейный выход:

```python
self.output = nn.Linear(hidden_size, 1)
```

Он переводит скрытое состояние каждого шага в одно число. Затем применяется `tanh`, чтобы выход был в диапазоне от `-1` до `1`:

```python
return torch.tanh(self.output(hidden))
```

Это удобно, потому что целевые значения тоже равны `-1` и `1`.

## Как обучается сеть Элмана

В функции `train_elman` входные массивы переводятся в тензоры PyTorch:

```python
x = torch.tensor(x_np, dtype=torch.float32, device=DEVICE).view(1, -1, 1)
y = torch.tensor(y_np, dtype=torch.float32, device=DEVICE).view(1, -1, 1)
```

Форма `view(1, -1, 1)` означает:

- `1` — один обучающий пример;
- `-1` — длина последовательности;
- `1` — один признак на каждом шаге.

В качестве функции ошибки используется MSE:

```python
criterion = nn.MSELoss()
```

MSE считает средний квадрат разности между ответом сети и правильным ответом. Если сеть вместо `1` выдала `0.8`, ошибка маленькая. Если вместо `1` выдала `-1`, ошибка большая.

Оптимизатор:

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
```

Adam автоматически подбирает направление изменения весов на основе градиентов. Это не тот же самый алгоритм, что `trainoss` в MATLAB, но смысл тот же: веса меняются так, чтобы ошибка уменьшалась.

После обучения выход сети переводится в классы:

```python
classes = np.where(prediction >= 0, 1, -1)
```

Правило простое:

- если выход больше или равен нулю, считаем, что сеть нашла `p2`;
- если выход меньше нуля, считаем, что идет основной сигнал `p1`.

Потом считается количество правильно распознанных точек.

## Проверка на измененной последовательности

После обучения сеть проверяется не только на исходном `R=[2,5,6]`, но и на измененном варианте `R=[2,4,6]`.

Это нужно, чтобы проверить, не запомнила ли сеть просто конкретную длину всей последовательности. Если она действительно научилась узнавать форму сигнала `p2`, то она должна работать и при немного другом количестве повторов фонового сигнала.

В ноутбуке строятся два графика:

- правильный целевой выход;
- фактический выход сети.

По графику видно, совпадают ли участки `1` и `-1`.

- `-1` — неактивный пиксель.

## Сеть Хопфилда

Сеть Хопфилда — это ассоциативная память.

Обычная память работает так: по адресу получаем значение.

Ассоциативная память работает иначе: по похожему объекту восстанавливаем целый объект.

Например, если в сеть заложены цифры `0`, `1`, `4`, то при подаче испорченной цифры `1` сеть должна вернуться к чистому эталону `1`.

## Как устроена сеть Хопфилда

В сети Хопфилда каждый нейрон связан почти со всеми остальными нейронами. В нашем случае один пиксель изображения — один нейрон.

Размер образа `12x10`, значит всего:

```text
12 * 10 = 120 нейронов
```

Каждый образ разворачивается в вектор длиной 120.

Веса строятся по правилу Хебба:

```python
weights += np.outer(vector, vector)
```

Внешнее произведение `np.outer(vector, vector)` показывает, какие пиксели должны быть связаны положительно, а какие отрицательно.

Если два пикселя в эталонном образе имеют одинаковый знак, связь между ними положительная.

Если знаки разные, связь отрицательная.

После добавления всех эталонов диагональ обнуляется:

```python
np.fill_diagonal(weights, 0.0)
```

Это делается потому, что нейрон не должен сам на себя влиять.

Затем веса делятся на размер образа:

```python
return weights / size
```

Это нормировка, чтобы значения весов не становились слишком большими.

## Как сеть Хопфилда восстанавливает образ

Восстановление выполняется итерационно:

```python
updated = np.sign(weights @ state)
```

Текущее состояние умножается на матрицу весов. Потом берется знак:

- положительное значение превращается в `1`;
- отрицательное значение превращается в `-1`.

Если состояние перестало меняться, сеть остановилась:

```python
if np.array_equal(updated, state):
    break
```

Это означает, что сеть пришла к устойчивому состоянию. В идеале это один из заложенных эталонов.

В лабораторной проверяются:

- чистая цифра `0`;
- цифра `1` с шумом 20%;
- цифра `4` с шумом 30%.

Шум добавляется так:

```python
mask = rng.random(pattern.shape) < amount
noisy[mask] *= -1
```

То есть часть пикселей случайно меняет знак.

Для защиты важно понимать: сеть Хопфилда не классифицирует образ напрямую. Она сначала пытается восстановить ближайший устойчивый образ, а уже потом мы сравниваем результат с эталонами.

## Сеть Хэмминга

Сеть Хэмминга решает задачу распознавания иначе.

Она не восстанавливает весь образ итерационно, как Хопфилд. Сначала она вычисляет близость входа к каждому эталону, а потом оставляет самый сильный ответ.

Расстояние Хэмминга — это количество несовпадающих позиций между двумя бинарными векторами.

Пример:

```text
эталон:  1  1 -1  1
вход:    1 -1 -1  1
```

Здесь не совпадает только вторая позиция, значит расстояние Хэмминга равно 1.

Чем меньше расстояние Хэмминга, тем больше похожи образы.

## Первый слой сети Хэмминга

В коде все эталоны складываются в матрицу:

```python
vectors = np.stack([p.reshape(-1) for p in patterns])
```

Затем считается начальная активация:

```python
activation = (vectors @ pattern.reshape(-1) + r).astype(np.float32)
```

Здесь:

- `vectors @ pattern` — скалярное произведение входа с каждым эталоном;
- `r` — размерность входного вектора, то есть 120.

Если вход похож на эталон, скалярное произведение будет большим. Если отличается — меньше.

Таким образом первый слой оценивает, насколько вход похож на каждую цифру.

## Второй слой сети Хэмминга

Второй слой реализует конкуренцию между классами.

Матрица латерального торможения:

```python
lateral = np.full((q, q), -eps, dtype=np.float32)
np.fill_diagonal(lateral, 1.0)
```

На диагонали стоит `1`: каждый класс поддерживает сам себя.

Вне диагонали стоит `-eps`: классы подавляют друг друга.

На каждой итерации применяется:

```python
new_activation = np.maximum(lateral @ activation, 0.0)
```

`np.maximum(..., 0.0)` — это аналог функции `poslin`, которая обнуляет отрицательные значения.

После нескольких итераций остается одна самая большая активация. Ее индекс и есть распознанный класс.

В ноутбуке для Хэмминга выводится:

- вектор активаций;
- выбранная цифра;
- визуализация входного образа;
- визуализация распознанного эталона;
- столбчатая диаграмма активаций для цифр `0`, `1`, `4`.

### Ячейка 7. Функции сети Хопфилда

Функция `train_hopfield` строит матрицу весов.

Каждый эталон разворачивается в вектор:

```python
vectors = [p.reshape(-1) for p in patterns]
```

Для изображения `12x10` получается вектор длины 120.

Веса накапливаются через внешнее произведение:

```python
weights += np.outer(vector, vector)
```

Это правило Хебба: если пиксели часто активны вместе, связь между ними усиливается.

Функция `run_hopfield` выполняет восстановление. На каждой итерации считается новое состояние:

```python
updated = np.sign(weights @ state)
```

Если состояние больше не меняется, цикл останавливается.

### Ячейка 8. Проверка сети Хопфилда

### Ячейка 9. Функция сети Хэмминга

Функция `hamming_classify` реализует распознавание через близость к эталонам.

Сначала эталоны собираются в матрицу:

```python
vectors = np.stack([p.reshape(-1) for p in patterns])
```

Начальная активация:

```python
activation = (vectors @ pattern.reshape(-1) + r).astype(np.float32)
```

Чем больше совпадений с эталоном, тем выше активация.

Матрица `lateral` задает конкуренцию классов:

```python
lateral = np.full((q, q), -eps)
np.fill_diagonal(lateral, 1.0)
```

Класс поддерживает сам себя, но подавляет остальные классы.

Функция `np.maximum(..., 0.0)` играет роль `poslin`: отрицательные активации обнуляются.

На выходе возвращается:

- вектор активаций;
- индекс максимальной активации.
