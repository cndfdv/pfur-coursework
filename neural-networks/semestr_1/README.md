# Нейронные сети — первый семестр, ПФУР

Шесть лабораторных работ с ноутбуками, отчётами и сгенерированными иллюстрациями.
Работы второго семестра находятся в соседнем каталоге [`../semestr_2/`](../semestr_2/).

## Структура

- `lab_1` — `lab_6/` — отдельные лабораторные;
- `main.ipynb` в каждом каталоге — исходный ноутбук;
- `explanation.md` и `comments.md` — пояснения к работе;
- `report_lab*.pdf` и `report_lab*.docx` — готовые отчёты;
- `figures/` — сохранённые графики и схемы.

## Запуск лабораторной

Откройте `lab_1/main.ipynb` — `lab_6/main.ipynb` в JupyterLab и выполняйте ячейки
сверху вниз. Зависимости и входные данные проверяйте по коду выбранного ноутбука.
Для чтения результатов без выполнения используйте готовые PDF-отчёты.
