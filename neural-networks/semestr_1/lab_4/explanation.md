## Общая идея лабораторной

В этой лабораторной изучается обычная глубокая полносвязная нейронная сеть. Такую сеть еще называют:

- MLP;
- multilayer perceptron;
- многослойный персептрон;
- сеть прямого распространения.

Сеть называется сетью прямого распространения, потому что данные идут только вперед:

```text
вход -> скрытый слой 1 -> скрытый слой 2 -> ... -> выход
```

В ней нет циклов, памяти и обратных связей, как в рекуррентных сетях.

## Что такое нейрон в полносвязной сети

Один искусственный нейрон получает несколько входных чисел. Например:

```text
x1, x2, x3
```

Для каждого входа у нейрона есть вес:

```text
w1, w2, w3
```

Нейрон считает взвешенную сумму:

```text
z = w1*x1 + w2*x2 + w3*x3 + b
```

Здесь `b` — смещение. Оно нужно, чтобы нейрон мог сдвигать границу решения.

После этого применяется функция активации:

```text
a = activation(z)
```

Без функции активации несколько линейных слоев подряд свелись бы к одному линейному преобразованию. Нейросеть не смогла бы строить сложные нелинейные зависимости.

## Что такое слой

Слой — это набор нейронов, которые получают один и тот же вход, но имеют разные веса.

В PyTorch полносвязный слой задается так:

```python
nn.Linear(input_size, output_size)
```

Например:

```python
nn.Linear(5000, 16)
```

Это значит:

- на вход слоя приходит вектор длиной 5000;
- на выходе получается 16 чисел;
- внутри слоя 16 нейронов.

## Что значит архитектура `16-32-16`

Для варианта 13 в первом этапе сеть имеет три скрытых слоя:

```text
вход -> 16 -> 32 -> 16 -> выход
```

То есть:

- первый скрытый слой содержит 16 нейронов;
- второй скрытый слой содержит 32 нейрона;
- третий скрытый слой содержит 16 нейронов;
- выходной слой содержит 1 нейрон, потому что задача бинарная.

В коде сеть создается функцией:

```python
make_mlp(input_size, [16, 32, 16], ["relu", "relu", "tanh"], 1)
```

Здесь:

- `input_size` — размер входного вектора;
- `[16, 32, 16]` — количество нейронов в скрытых слоях;
- `["relu", "relu", "tanh"]` — функции активации после скрытых слоев;
- `1` — размер выхода.

## Функции активации

В лабораторной используются несколько функций активации.

### ReLU

```text
ReLU(x) = max(0, x)
```

Если число отрицательное, ReLU возвращает 0. Если положительное — оставляет как есть.

Плюсы ReLU:

- простая;
- быстро считается;
- часто хорошо работает в глубоких сетях.

### Tanh

```text
tanh(x) in [-1, 1]
```

Гиперболический тангенс сжимает значения в диапазон от `-1` до `1`.

Он полезен, когда нужно получить симметричные относительно нуля признаки.

### Mish

Mish — более современная гладкая функция активации.

Она похожа на ReLU по смыслу, но не имеет резкого излома в нуле. В некоторых задачах это помогает обучению.

В коде:

```python
nn.Mish()
```

## Этап 1. Бинарная классификация IMDB

В первом этапе решается задача классификации отзывов:

- `0` — отрицательный отзыв;
- `1` — положительный отзыв.

Архив IMDB читается из локального файла:

```python
texts, y = read_imdb(Path("IMDB/aclImdb.zip"), max_docs_per_class=700)
```

Функция `read_imdb` открывает zip-архив и берет тексты из папок:

```text
aclImdb/train/neg
aclImdb/train/pos
aclImdb/test/neg
aclImdb/test/pos
```

Метки задаются так:

- папка `neg` получает класс `0`;
- папка `pos` получает класс `1`.

## Как текст превращается в числа

Нейросеть не умеет напрямую работать со строками. Ей нужны числа.

Для этого используется `CountVectorizer`:

```python
vectorizer = CountVectorizer(max_features=5000, binary=True, stop_words="english")
```

Он строит словарь из наиболее частых слов. В лабораторной максимум 5000 признаков.

Каждый отзыв превращается в вектор:

```text
[0, 1, 0, 0, 1, ...]
```

Если слово есть в отзыве, на соответствующей позиции стоит `1`. Если слова нет — `0`.

Параметр `binary=True` означает, что мы не считаем количество повторов слова. Нас интересует только факт наличия слова.

Параметр `stop_words="english"` убирает частые служебные слова английского языка.

## Разделение данных

Данные делятся на три части:

- обучающая выборка;
- валидационная выборка;
- тестовая выборка.

Обучающая выборка нужна для изменения весов.

Валидационная выборка нужна, чтобы смотреть качество во время обучения.

Тестовая выборка нужна для финальной оценки после обучения.

В коде используется `train_test_split` со `stratify=y`. Это важно: в каждой части сохраняется примерно одинаковое соотношение положительных и отрицательных отзывов.

## Модель IMDB по варианту

Модель варианта:

```python
imdb_model = nn.Sequential(
    make_mlp(x_train.shape[1], [16, 32, 16], ["relu", "relu", "tanh"], 1),
    nn.Sigmoid(),
)
```

Здесь после выходного слоя стоит `Sigmoid`.

Sigmoid переводит число в диапазон от `0` до `1`. Это удобно для бинарной классификации, потому что результат можно воспринимать как вероятность положительного отзыва.

Правило классификации:

```python
pred = output >= 0.5
```

Если выход больше или равен `0.5`, отзыв считается положительным.

Если меньше `0.5`, отзыв считается отрицательным.

## Почему в варианте используется MSE

По заданию для варианта 13 на первом этапе используется среднеквадратическая ошибка:

```python
nn.MSELoss()
```

MSE обычно чаще используется в регрессии, но в задании она дана для бинарной классификации. В таком случае сеть учится приближать ответ к числу `0` или `1`.

Для сравнения в коде есть базовая модель:

```python
imdb_baseline = make_mlp(x_train.shape[1], [16, 16], ["relu", "relu"], 1)
```

Она обучается с `BCEWithLogitsLoss`, то есть с бинарной кросс-энтропией.

Бинарная кросс-энтропия лучше соответствует задаче классификации, потому что напрямую штрафует неправильную вероятность класса.

Используется датасет Reuters из Keras/TensorFlow datasets. Это набор коротких новостных текстов, где каждый текст относится к одной из тематических категорий. В классической версии набора 46 классов.

В ноутбуке файл берется так:

```python

```

Функция `local_dataset_file` ищет заранее скачанный локальный файл:

```text

```

Скачивания внутри ноутбука нет. Это сделано специально, чтобы на защите ноутбук не зависел от интернета. Если файла нет, код сразу выдаст понятную ошибку и попросит положить `reuters.npz` в папку `data`.

```python
NUM_WORDS = 10000
```

То есть сеть использует 10000 наиболее важных возможных индексов слов.

## Модель многоклассовой классификации

Архитектура варианта:

```python
multi_model = make_mlp(
    x_train.shape[1],
    [32, 64, 64],
    ["tanh", "mish", "relu"],
    num_classes,
)
```

Выходной слой имеет столько нейронов, сколько классов Reuters.

Если классов 46, выходной слой выдает 46 логитов:

```text
[2.1, -0.7, 0.4, ..., 1.2]
```

Это не вероятности, а логиты. Для выбора класса берется индекс максимального значения:

```python
logits.argmax(dim=1)
```

Функция потерь:

```python
nn.CrossEntropyLoss()
```

Она внутри сочетает `softmax` и отрицательное логарифмическое правдоподобие. Поэтому вручную добавлять `Softmax` в модель не нужно.

## Этап 3. Boston Housing: регрессия

Регрессия отличается от классификации тем, что сеть предсказывает не класс, а число.

Примеры регрессии:

- цена квартиры;
- температура;
- расход топлива;
- оценка стоимости.

В задании используется Boston Housing. Это набор признаков районов Бостона, по которым нужно предсказывать стоимость жилья.

В ноутбуке файл берется так:

```python
boston_path = local_dataset_file("boston_housing.npz")
```

Как и для Reuters, код ищет заранее скачанный локальный файл:

```text
data/boston_housing.npz
../data/boston_housing.npz
```

Скачивания внутри ноутбука нет. Файл `boston_housing.npz` должен лежать в папке `data`.

В Boston Housing входные данные — числовые признаки. Перед обучением они стандартизируются:

```python
x = StandardScaler().fit_transform(x).astype("float32")
```

Это нужно, чтобы признаки были одного масштаба и сеть обучалась стабильнее.

Архитектура такая же, как по варианту:

```python
reg_model = make_mlp(
    x.shape[1],
    [32, 64, 64],
    ["tanh", "mish", "relu"],
    1,
)
```

Выход один, потому что предсказывается одно число.

Функция потерь:

```python
nn.MSELoss()
```

MSE хорошо подходит для регрессии, потому что штрафует большие ошибки сильнее маленьких.

Дополнительно считается MAE:

```python
np.mean(np.abs(pred - y[val_idx]))
```

MAE — средняя абсолютная ошибка. Она проще интерпретируется: в среднем модель ошибается на столько-то единиц целевой величины.

## K-fold проверка

В регрессии используется перекрестная проверка по `K=4` блокам.

Идея такая:

1. Данные делятся на 4 части.
2. Сеть обучается на трех частях.
3. Проверяется на оставшейся части.
4. Процесс повторяется 4 раза, чтобы каждая часть один раз стала проверочной.

Так оценка получается надежнее, чем при одном случайном разбиении.

В коде:

```python
kfold = KFold(n_splits=4, shuffle=True, random_state=SEED)
```

## Что делает функция `train_model`

Это общая функция обучения для всех трех этапов.

Внутри каждой эпохи:

1. Модель переводится в режим обучения:

```python
model.train()
```

2. Для каждого batch считаются предсказания:

```python
out = model(x)
```

3. Считается ошибка:

```python
loss = criterion(out, y)
```

4. Обнуляются старые градиенты:

```python
optimizer.zero_grad()
```

5. Выполняется обратное распространение ошибки:

```python
loss.backward()
```

6. Оптимизатор меняет веса:

```python
optimizer.step()
```

7. После эпохи считается качество на валидационной выборке.

### Ячейка 2. Создание MLP и DataLoader

Функция `activation` возвращает объект функции активации по строковому имени:

```python
"relu" -> nn.ReLU()
"tanh" -> nn.Tanh()
"mish" -> nn.Mish()
```

Это удобно, потому что в варианте активации записаны словами.

Функция `make_mlp` собирает полносвязную сеть:

```python
make_mlp(input_size, hidden, activations, output_size)
```

Она проходит по списку скрытых слоев. Для каждого слоя добавляет:

1. `nn.Linear`;
2. функцию активации.

В конце добавляется выходной слой без активации:

```python
layers.append(nn.Linear(prev, output_size))
```

Так можно одной функцией построить все сети лабораторной: IMDB, Reuters, Boston Housing и базовые модели.

Функция `make_loader` превращает массивы NumPy в `TensorDataset`, а затем в `DataLoader`.

`DataLoader` нужен, чтобы обучать сеть batch-ами, а не подавать все данные сразу.

### Ячейка 3. Подсчет accuracy, evaluation и обучение

Функция `count_correct` считает количество правильных ответов.

Для регрессии accuracy не считается, поэтому возвращается 0.

Для многоклассовой классификации:

```python
logits.argmax(dim=1)
```

выбирает класс с максимальным логитом.

Для бинарной классификации есть два режима:

- `binary_probability` — модель уже выдает вероятность после `Sigmoid`;
- `binary` — модель выдает логит, поэтому применяется `torch.sigmoid`.

Функция `evaluate` проверяет модель на validation или test. В ней используется:

```python
model.eval()
```

Это переводит модель в режим проверки. Например, dropout в этом режиме отключается.

Блок:

```python
with torch.no_grad():
```

говорит PyTorch не строить граф вычислений. Это ускоряет проверку и экономит память.

Функция `train_model` — общий цикл обучения. В каждой эпохе:

1. модель получает batch;
2. считает выход;
3. считается ошибка;
4. делается `loss.backward()`;
5. оптимизатор обновляет веса через `optimizer.step()`;
6. после эпохи считается validation loss и validation accuracy.

История обучения сохраняется в словарь `history`, чтобы потом построить графики.

### Ячейка 7. Обучение IMDB-модели и базовой модели

```python
)
```

После MLP добавлен `Sigmoid`, потому что по варианту используется MSE и удобно сравнивать выход с метками `0` и `1`.

Базовая модель:

```python
imdb_baseline = make_mlp(..., [16, 16], ["relu", "relu"], 1)
```

Она обучается через `BCEWithLogitsLoss`, поэтому `Sigmoid` внутри модели не нужен.

После обучения печатаются test loss и test accuracy для обеих моделей, затем строятся графики.

### Ячейка 9. Boston Housing: регрессия и K-fold

Файл Boston Housing читается локально:

```python
boston_path = local_dataset_file("boston_housing.npz")
```

Внутри:

- `x` — признаки домов и районов;
- `y` — целевая стоимость.

Признаки стандартизируются:

```python
x = StandardScaler().fit_transform(x)
```

Это важно для MLP, потому что признаки в разных масштабах мешают стабильному обучению.

Дальше создается K-fold:

```python
KFold(n_splits=4, shuffle=True, random_state=SEED)
```

Для каждого fold обучаются две модели:

- модель варианта `32-64-64`, `tanh-mish-relu`;
- базовая модель `64-64`, `relu-relu`.

Качество считается через MAE:

```python
np.mean(np.abs(pred - y[val_idx]))
```

MAE показывает среднюю абсолютную ошибку прогноза цены.

В конце выводятся MAE по всем 4 блокам и среднее значение.

## Что важно уметь объяснить на защите

1. Полносвязная сеть состоит из слоев `Linear` и функций активации.

2. Функции активации нужны, чтобы сеть могла строить нелинейные зависимости.

3. Для бинарной классификации выход один, а класс определяется по порогу.

4. Для многоклассовой классификации выходов столько, сколько классов, а выбирается максимальный логит.

5. Для регрессии выход один и воспринимается как предсказанное число.

6. MSE измеряет квадрат ошибки, CrossEntropy используется для классификации, BCEWithLogitsLoss — для бинарной классификации.

7. Валидационная выборка нужна для контроля обучения, тестовая — для итоговой оценки.

8. K-fold проверка дает более устойчивую оценку качества регрессионной модели.

Дополнительно была обучена базовая модель `16-16` с бинарной кросс-энтропией, чтобы можно было сравнить вариант с более стандартным подходом для бинарной классификации.

На этапе Reuters была решена многоклассовая задача. Новости представлены как последовательности индексов слов, которые затем переводятся в бинарные векторы признаков. Модель варианта `32-64-64` с активациями `tanh-mish-relu` выдает логиты по всем классам Reuters, а функция `CrossEntropyLoss` обучает сеть выбирать правильную тему новости.

Итог: одна и та же базовая идея MLP может применяться к разным задачам, но выходной слой, функция потерь и способ оценки качества должны соответствовать типу задачи.
