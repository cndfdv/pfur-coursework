# Анализ больших данных — лабораторные работы ПФУР

Учебный репозиторий по анализу данных в рамках курса ПФУР.

## Содержание

- `lab_2/main.ipynb` — ноутбук практической работы;
- `lab_2/data/README.md` — описание данных;
- `lab_2/presentation/` — презентация и текст выступления;
- `lab_2/Задачи (1).pptx` — файл с задачами.

## Запуск

Откройте `lab_2/main.ipynb` в Jupyter. Ноутбук читает Excel-файлы; каталог с ними и ожидания по `ROOT`/`VPO_ROOT` описаны в [`lab_2/data/README.md`](lab_2/data/README.md). После переноса ноутбука из `notebooks/` заданное в нём значение `ROOT` может указывать не на каталог данных, поэтому проверьте пути перед запуском. В ноутбуке используются NumPy, pandas и Plotly; отдельный файл зависимостей для этой работы не найден.
