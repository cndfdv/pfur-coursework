# Исходные данные

Сейчас исходных Excel-файлов в репозитории нет. `../main.ipynb` читает таблицы Excel из корня работы и вложенных каталогов, а файлы ВПО — из каталога `_extracted/`. Ищутся файлы с именами и структурами, заданными в ноутбуке, в том числе файлы `*Россия*.xlsx`, `*СПО1*ВСЕГО*.xls*`, сводки `Свод_ВПО1_Всего*.xls*` и `Chisl_polvozr_01-01-*_VPN-2020.xlsx`.

Для анализа нужны соответствующие исходные Excel-файлы в ожидаемой структуре каталогов. В ноутбуке `ROOT = Path("..").resolve()` и `VPO_ROOT = ROOT / "_extracted"`; после переноса ноутбука из `notebooks/` эти пути и комментарий о его расположении устарели. Настройте `ROOT` и `VPO_ROOT` под фактическое расположение файлов перед запуском. Без исходных таблиц ноутбук не сможет сформировать входные таблицы.
