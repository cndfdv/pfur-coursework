# RAG по статьям Хабра

Учебная лабораторная: LangChain, рекурсивные чанки, локальный эмбеддер VK,
гибридный поиск BM25 + FAISS и ответы DeepSeek V4 Flash через официальный API.
Интерфейс — Streamlit. Отдельный `main.ipynb` показывает очистку одной статьи.

## Файлы

- `chunking.py` — потоковое чтение JSON, очистка HTML, удаление дублей, чанкинг.
- `retrival.py` — эмбеддинги, FAISS, BM25 и объединение результатов через RRF.
- `llm.py` — запрос DeepSeek через LangChain, ответ со ссылками `[1]`, `[2]`.
- `app.py` — интерфейс: вопрос, ответ, найденные фрагменты и ссылки.
- `main.ipynb` — пошаговый разбор JSON, HTML, очистки и чанкинга первой статьи.
- `data/habr_hub_search.json` — исходная выгрузка; программа её не меняет.

## Docker

Из папки `first_lab` при работающем Docker Desktop:

```bash
docker compose up --build -d
```

Открыть http://localhost:8501 и нажать «Собрать базу знаний».
Первый запуск скачивает `deepvk/USER2-small` (~140 МБ весов); модель сохраняется
в Docker volume `model-cache`. Данные подключены только для чтения и не входят
в образ. Индексы находятся в памяти и после перезапуска собираются заново.
Параметры задаются в коде: `ARTICLE_LIMIT = 500` в `app.py` — количество
загружаемых статей; `TOP_K = 10` — количество найденных чанков для LLM.
Для быстрой пробы можно поставить `ARTICLE_LIMIT = 10`.
После изменения данных или параметров перезапустить приложение;
для Docker повторить `docker compose up --build -d`.

Ключ DeepSeek можно ввести в поле интерфейса. Другой вариант — задать переменную
`DEEPSEEK_API_KEY` перед `docker compose up -d` (Compose также читает локальный
`.env`, который исключён из Git). Без ключа приложение показывает только источники.
В API передаются вопрос и найденные фрагменты, а не вся выгрузка.

```bash
docker compose logs -f rag
docker compose down
```

## Локальный запуск через mamba

```bash
mamba create -y -p ./.mamba python=3.12 pip
mamba run -p ./.mamba python -m pip install -r requirements.txt
mamba run -p ./.mamba python -m streamlit run app.py
```

## Данные и алгоритм

Для изучения очистки откройте `main.ipynb` в VS Code/Jupyter, выберите Python
из `.mamba` и выполните ячейки сверху вниз. При необходимости установите ядро:
`mamba run -p ./.mamba python -m pip install ipykernel`.
Ноутбук читает только первую статью, не скачивает эмбеддер и не вызывает API.

Файл размером около 1,8 ГБ имеет структуру `{хаб: [статьи]}`. Читаем по одной
статье через `ijson`, потому что `json.load` загрузил бы всю выгрузку в память.
Полный потоковый подсчёт 04.09.2026: 50 372 записи в 7 хабах,
41 045 уникальных ID, 9325 повторных вхождений ID и 2 записи без ID.
Используем заголовок и `textHtml`, а при отсутствии текста — анонс
`leadData.textHtml` с отметкой в источнике. Удаляем HTML-теги, скрипты, стили,
лишние пробелы и пустые тексты. Сохраняем абзацы и текст кода; изображения,
оформление таблиц и исходные отступы кода в RAG не переносятся. Служебные поля
пользователей, статистики и интерфейса Хабра не индексируются.
Дубли отсекаются по ID и хешу очищенного текста с заголовком.

Берём первые 500 уникальных непустых статей по порядку файла. Это учебная
подвыборка, а не репрезентативная выборка всех хабов. Параметр `limit=None`
у `load_documents` читает весь корпус, но построение индексов потребует
значительно больше времени и памяти. Все ограничения задаются в коде.

`RecursiveCharacterTextSplitter`: 1000 символов, перекрытие 150. VK-эмбеддер
использует префиксы `search_document` и `search_query`, нормализованные векторы
и CPU. BM25 приводит слова к нижнему регистру и заменяет «ё» на «е», без
лемматизации. Каждый поиск отдаёт до 20 кандидатов, RRF складывает
`1 / (60 + позиция)` с равными весами; в LLM уходят лучшие 10 чанков.
BM25-кандидаты без общих слов с вопросом отбрасываются. Оценка RRF не является
вероятностью релевантности. Несколько фрагментов могут относиться к одной статье.

DeepSeek отвечает отдельно на каждый вопрос, без истории диалога. Температура
0.2, до 1500 токенов ответа, thinking отключён, timeout 60 секунд, два повтора.
Отсутствие подходящих сведений в выбранных статьях должно отражаться в ответе;
ссылки и утверждения модели всё равно стоит сверять с показанными фрагментами.

## Проверка

Тестовые файлы не добавляются. Проверка вручную: сборка Docker, health endpoint,
индексация небольшой части реального JSON, гибридный поиск и просмотр источников
в интерфейсе. Ответ API требует действующего ключа DeepSeek.

Замер 04.09.2026 в локальном mamba-окружении: первые 500 статей прочитаны
и очищены за 2,65 с, разбиты на 9454 чанка за 0,16 с. Среди этих 500 записей
не было дублей, пустых текстов и записей только с анонсом. Это результат
для начала файла, а не аудит всех 1,8 ГБ; время импорта библиотек, скачивания
модели и построения эмбеддингов в эти числа не входит.

`main.ipynb` выполнен с чистого ядра из `.mamba`: все 10 ячеек с кодом
завершились без ошибок, результаты сохранены. У первой статьи 34 поля;
HTML размером 4766 символов превращается в 4063 символа текста и 5 чанков.
