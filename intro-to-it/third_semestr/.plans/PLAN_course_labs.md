# PLAN: лабораторные 2–5 по RAG

## Status

READY: yes

## Goal

Оформить папку третьего семестра и выполнить четыре задания из актуальных
презентаций так, чтобы код можно было объяснить на защите.

## Scope

- `lab_2_langchain`: LangChain RAG по статьям Хабра с веб-интерфейсом.
- `lab_3_langgraph`: три источника по 10 000 текстов, маршрутизация запроса,
  самопроверка, одна самокоррекция, промежуточные шаги и схема графа.
- `lab_4_costs`: разговорные и поисковые запросы, исправление опечаток,
  составные вопросы и Cost Dashboard.
- `lab_5_security`: обнаружение и нейтрализация прямой и косвенной
  Prompt Injection с воспроизводимой демонстрацией.
- Тяжёлые индексы строятся на `ssh home`, GPU RTX 4060 Ti, mamba `main`.

## Decisions

- Версии презентаций с `(1)` считаются актуальными: в них есть Light-варианты
  и дополнительные ссылки на наборы данных.
- Лабораторные используют общий небольшой пакет `shared`, чтобы не копировать
  загрузчики, эмбеддер и вызов LLM.
- Данные и индексы не входят в Git. Скрипт загрузки сохраняет их на сервере.
- Эмбеддер: `deepvk/USER2-small`; документы и запросы получают рекомендованные
  префиксы `search_document` и `search_query`.
- По уточнению пользователя LLM — `gpt-6-luna`, reasoning effort `medium`,
  Responses API через LangChain. Ключ `OPENAI_API_KEY`.
- Для Cost Dashboard: $0.10 / 1M входных, $0.01 / 1M кэшированных входных,
  $0.50 / 1M выходных токенов. Цены вынесены в настройки.
- Web fallback не обязателен: формулировка задания разрешает генерацию LLM.
- Отдельные тестовые файлы не добавляются. Проверка выполняется на реальных
  данных и небольших smoke-сценариях, как просил пользователь.

## Verification

- `python -m compileall` для исходников.
- Потоковый разбор и статистика каждого набора данных.
- Построение 3 индексов по 10 000 текстов на удалённой GPU.
- Один retrieval-запрос к каждому источнику.
- LangGraph-сценарии: обычный запрос, нерелевантный запрос, составной запрос.
- Security-сценарии: безопасный ввод, прямая атака, заражённый чанк.
- Streamlit smoke и визуальная проверка основных экранов.
- Реальный вызов GPT-6 Luna выполняется только при наличии `OPENAI_API_KEY`.

## Risks

- Формат Google Drive файлов неизвестен до загрузки. Загрузчик выбирается после
  проверки сигнатуры и схемы, без изменения исходных файлов.
- Цены API изменяются. README содержит дату и ссылку, а параметры стоимости
  можно переопределить переменными окружения.
- Без API-ключа нельзя подтвердить качество итоговой генерации LLM.
