# Lab 3: LangGraph RAG

## Задание

Использовать по 10 000 текстов из Хабра, научных статей и новостей. Определять
источник по вопросу, проверять найденные документы, исправлять неудачный поиск,
показывать промежуточные шаги и визуализировать граф.

## Граф

1. `classify` выбирает `habr`, `science`, `news` или разговорный ответ.
2. `retrieve` ищет десять чанков в выбранном FAISS-индексе.
3. `grade` проверяет cosine score. Порог равен 0.25.
4. `rewrite` один раз упрощает запрос, если результат слабый.
5. `generate` формирует ответ по документам. После неудачного повторного поиска
   допускается ответ из знаний LLM с явной пометкой, без ссылок на корпус.
6. `check` проверяет номера ссылок, а при наличии ключа просит LLM оценить
   подтверждение ответа документами. Неподтверждённый после повтора ответ скрывается.

Число повторов ограничено единицей, поэтому граф всегда завершается.

## Запуск

Сначала установите зависимости, загрузите данные и постройте индексы по
[общей инструкции](../README.md). Затем из `intro-to-it/third_semestr`:

```bash
~/miniforge3/bin/mamba run -n main streamlit run lab_3_langgraph/app.py
```

Без `OPENAI_API_KEY` работает локальный режим: при релевантном поиске показывается
начало лучшего фрагмента, при неудачном — сообщение об отсутствии ответа.
Это позволяет проверить маршрутизацию отдельно от API.

План: построить три индекса → проверить маршруты → показать цикл коррекции →
сравнить ответ и источники. Для защиты: «Привет!», «Как работает Python?»,
«Какие научные исследования посвящены нейросетям?», «Какие новости об экономике?».

Маршрутизация по ключевым словам и порог cosine 0.25 — учебные эвристики.
Они не гарантируют релевантность; LLM-самопроверка также может ошибаться.
Для запросов со смешанными темами используйте разбиение в лабораторной 4.
