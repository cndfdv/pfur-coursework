# Введение в ИТ — лабораторные работы ПФУР

Учебный репозиторий по основам программирования и информационных технологий.

## Структура

- `first_semestr/` — лабораторные первого семестра в формате Jupyter Notebook;
- `second_semestr/` — задания по Python, обработке данных, валидации, тестированию и файловому вводу-выводу;
- в лабораторных с тестами используются `pytest` и локальные тестовые данные.

## Запуск

Откройте нужный `.ipynb` в JupyterLab или Google Colab. Для Python-работ с тестами перейдите в каталог конкретной лабораторной и выполните:

```bash
python -m pytest
```

Это учебная коллекция, поэтому единая точка запуска отсутствует.
