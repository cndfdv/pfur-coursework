## Общая идея лабораторной

В этой лабораторной изучаются сверточные нейронные сети, или CNN.

CNN чаще всего используют для изображений, потому что изображение имеет пространственную структуру:

- рядом стоящие пиксели связаны друг с другом;
- объект может находиться в разных частях изображения;
- важны локальные признаки: края, углы, линии, текстуры, части формы.

Обычная полносвязная сеть плохо подходит для изображений. Если изображение `200x200` и 3 цветовых канала, то вход имеет:

```text
200 * 200 * 3 = 120000 признаков
```

Если сразу подключить такой вход к полносвязному слою, получится слишком много параметров. Сверточная сеть решает эту проблему за счет фильтров.

## Что такое свертка

Свертка — это операция, при которой маленькое окно проходит по изображению и ищет определенный признак.

Например, фильтр `3x3` смотрит только на маленький участок:

```text
пиксель пиксель пиксель
пиксель пиксель пиксель
пиксель пиксель пиксель
```

Один фильтр может научиться находить вертикальные линии, другой — горизонтальные края, третий — углы.

В PyTorch сверточный слой задается так:

```python
nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1)
```

Здесь:

- `in_channels` — сколько каналов приходит на вход;
- `out_channels` — сколько карт признаков будет на выходе;
- `kernel_size=3` — размер фильтра `3x3`;
- `padding=1` — добавление рамки вокруг изображения, чтобы после свертки размер не уменьшался.

## Что такое карта признаков

Карта признаков — это результат работы одного фильтра.

Если фильтр ищет вертикальные линии, то на выходной карте будут большие значения там, где сеть нашла вертикальные линии.

Если у слоя `64` карты признаков, значит в нем `64` разных фильтра. Каждый фильтр ищет свой тип локального признака.

В варианте 13 для MNIST указано:

```text
64-128-128-256
```

Это значит:

- первый сверточный слой строит 64 карты признаков;
- второй — 128;
- третий — 128;
- четвертый — 256.

Чем глубже слой, тем более сложные признаки он может выделять.

На первых слоях сеть обычно учит простые признаки:

- края;
- линии;
- контуры.

На более глубоких слоях:

- части цифр;
- формы;
- комбинации признаков.

## Что такое MaxPooling

Pooling уменьшает размер карты признаков.

В коде используется:

```python
nn.MaxPool2d(2)
```

Это означает, что окно `2x2` заменяется одним максимальным значением.

Например:

```text
1  3
2  0
```

После max pooling получится `3`.

Зачем нужен pooling:

- уменьшает размер данных;
- уменьшает количество вычислений;
- делает признаки менее чувствительными к небольшим сдвигам объекта;
- помогает бороться с переобучением.

## Что такое классификатор после сверточной основы

Сверточная часть извлекает признаки из изображения.

После нее признаки нужно превратить в класс. Для этого используется полносвязный классификатор.

Схема CNN:

```text
изображение -> сверточная основа -> признаки -> полносвязный классификатор -> класс
```

В коде признаки разворачиваются:

```python
nn.Flatten()
```

Потом идут полносвязные слои:

```python
nn.Linear(256 * 7 * 7, 512)
nn.ReLU()
nn.Dropout(0.3)
nn.Linear(512, 10)
```

Для MNIST выходов 10, потому что классы — цифры от `0` до `9`.

## Этап 1. MNIST

MNIST — набор изображений рукописных цифр.

Каждое изображение:

- черно-белое;
- размером `28x28`;
- содержит одну цифру от `0` до `9`.

В коде данные загружаются так:

```python

```

`download=False` означает, что ноутбук ожидает локально скачанный датасет в папке `data`.

Преобразования:

```python

```

`ToTensor` переводит картинку в тензор PyTorch.

`Normalize` нормализует значения пикселей. Это помогает сети обучаться стабильнее.

Если локальный MNIST не найден, в коде есть резервный вариант через `sklearn.datasets.load_digits`. Он нужен только чтобы ноутбук не ломался в офлайн-среде. Основной вариант — настоящий MNIST.

## Архитектура MNIST по варианту

В коде:

```python
self.features = nn.Sequential(
    nn.Conv2d(1, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 128, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(128, 128, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(128, 256, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
)
```

Разбор:

- вход имеет 1 канал, потому что MNIST черно-белый;
- первый слой делает 64 карты признаков;
- второй — 128;
- после второго слоя pooling уменьшает размер с `28x28` до `14x14`;
- третий слой оставляет 128 карт;
- четвертый делает 256 карт;
- второй pooling уменьшает размер с `14x14` до `7x7`.

После этого на вход классификатора приходит:

```text
256 * 7 * 7 признаков
```

Классификатор:

```python
nn.Linear(256 * 7 * 7, 512)
nn.ReLU()
nn.Dropout(0.3)
nn.Linear(512, 10)
```

`Dropout(0.3)` во время обучения случайно отключает часть нейронов. Это уменьшает переобучение.

## Функция потерь для MNIST

```python

```

Она подходит для задач, где нужно выбрать один класс из нескольких.

Сеть выдает 10 логитов. Правильным считается класс с максимальным логитом:

```python

```

## Функция потерь Cats vs Dogs

Используется:

```python
nn.BCEWithLogitsLoss()
```

Это стандартная функция потерь для бинарной классификации.

Она принимает логит, то есть необработанный выход сети. Поэтому `Sigmoid` в саму модель добавлять не нужно.

Для подсчета accuracy в коде применяется:

```python
torch.sigmoid(logits) >= 0.5
```

То есть:

- если вероятность больше или равна `0.5`, это собака;
- если меньше `0.5`, это кошка.

## Этап 3. Transfer learning

Transfer learning — это перенос обучения.

Идея: взять сеть, которая уже обучалась на большом наборе изображений, и использовать ее признаки для своей задачи.

Например, ResNet18, обученная на ImageNet, уже умеет находить:

- края;
- текстуры;
- формы;
- части объектов;
- сложные визуальные признаки.

Для задачи Cats vs Dogs не обязательно обучать всю сеть с нуля. Можно взять готовую сверточную основу и заменить только классификатор.

## Заморозка сверточной основы

В коде:

```python
for parameter in transfer_model.parameters():
    parameter.requires_grad = False
```

Это означает, что веса сверточной основы не будут изменяться при обучении.

Затем заменяется последний слой:

```python
transfer_model.fc = nn.Sequential(
    nn.Linear(transfer_model.fc.in_features, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 1),
)
```

Теперь обучается только новый классификатор.

Проверка количества обучаемых параметров:

```python
trainable = sum(p.numel() for p in transfer_model.parameters() if p.requires_grad)
```

Если заморозка сделана правильно, обучаемых параметров намного меньше, чем всех параметров ResNet.

## Почему transfer learning полезен

Преимущества:

- нужно меньше данных;
- обучение идет быстрее;
- качество часто выше, чем при обучении маленькой CNN с нуля;
- меньше риск переобучения на маленьком датасете.

Недостаток:

- если предобученные веса не доступны локально, сеть создается без них. Архитектура остается такой же, но настоящий перенос признаков не работает.

В ноутбуке это обработано через `try/except`: если веса ResNet18 доступны, они загружаются; если нет, создается та же архитектура без предобученных весов.

## Что делает цикл обучения

Для каждой эпохи:

1. Модель переводится в режим обучения:

```python
model.train()
```

2. Берется batch изображений.

3. Считается выход сети:

```python
logits = model(x)
```

4. Считается ошибка:

```python
loss = criterion(logits, y)
```

5. Градиенты обнуляются:

```python
optimizer.zero_grad()
```

6. Выполняется backpropagation:

```python
loss.backward()
```

7. Оптимизатор обновляет веса:

```python
optimizer.step()
```

После каждой эпохи считается качество на валидационной выборке.


Размер `224x224` используется потому, что ResNet обучалась на изображениях такого размера.

Нормализация с указанными `mean` и `std` — стандартная нормализация ImageNet. Она нужна, если используются предобученные веса.

Дальше датасет снова делится на train, validation и test.

### Ячейка 10. Создание ResNet18 и заморозка основы

Сначала код пытается загрузить предобученные веса:

```python
weights = models.ResNet18_Weights.DEFAULT
transfer_model = models.resnet18(weights=weights)
```

Если веса недоступны, создается та же архитектура без них. Для настоящего transfer learning лучше иметь предобученные веса локально.

Потом все параметры замораживаются:

```python
for parameter in transfer_model.parameters():
    parameter.requires_grad = False
```

Это значит, что сверточная основа не будет обучаться.

Заменяется последний слой:

```python
transfer_model.fc = nn.Sequential(...)
```

Новый классификатор имеет скрытый слой 256 нейронов и один выход для бинарной классификации.

### Ячейка 11. Обучение transfer learning модели

Оптимизатор получает только обучаемые параметры:

```python
p for p in transfer_model.parameters() if p.requires_grad
```

То есть обновляется только новый классификатор, а замороженная основа не меняется.

Цикл обучения такой же, как для Cats vs Dogs:

- обучение на train;
- проверка на validation;
- финальная оценка на test;
- график loss и accuracy.

По заданию для варианта 13 указано 70 эпох, но для быстрой демонстрации на защите число эпох можно уменьшить константой `TRANSFER_EPOCHS`, не меняя архитектуру модели.

## Что важно уметь объяснить на защите

1. Сверточная сеть лучше подходит для изображений, потому что ищет локальные признаки фильтрами.

2. Сверточный слой строит карты признаков.

3. `kernel_size=3` означает фильтр `3x3`.

4. `padding=1` сохраняет пространственный размер после свертки `3x3`.

5. `MaxPool2d(2)` уменьшает изображение в 2 раза и оставляет наиболее сильные признаки.

6. `Flatten` превращает карты признаков в один длинный вектор для полносвязного классификатора.

7. Для MNIST выходов 10, потому что классов 10.

8. Для Cats vs Dogs выход один, потому что задача бинарная.

9. `BCEWithLogitsLoss` используется для бинарной классификации и принимает логиты.

10. Transfer learning замораживает сверточную основу и обучает новый классификатор.

11. Визуализации в ноутбуке показываются через `plt.show()`, а не сохраняются в отдельные файлы.

## Вывод

В лабораторной работе были реализованы сверточные нейронные сети для распознавания изображений и показан перенос обучения.

На этапе MNIST была построена CNN варианта 13: четыре сверточных слоя с картами признаков `64-128-128-256`, ядро `3x3` и полносвязный классификатор на 512 нейронов. Сверточная часть выделяет признаки цифр, pooling уменьшает размер карт признаков, а классификатор определяет одну из десяти цифр.

На этапе Cats vs Dogs была построена бинарная CNN для классификации кошек и собак. Так как по заданию рассматривается обучение на малом объеме данных, используется ограниченная подвыборка из архива, а не весь датасет целиком. Это ускоряет запуск и показывает типичную проблему маленьких выборок: модель может быстро переобучаться, поэтому важны validation-графики и dropout.

На этапе transfer learning использована архитектура ResNet18. Сверточная основа замораживается, а вместо исходного классификатора ставится новый бинарный классификатор. Такой подход полезен, потому что предобученная сеть уже умеет выделять общие визуальные признаки, а для новой задачи нужно обучить меньше параметров.

Итог: CNN хорошо подходит для изображений, потому что использует локальные фильтры и карты признаков. Transfer learning позволяет использовать готовую сверточную основу и обычно особенно полезен при небольшом количестве обучающих изображений.
