# Лабораторная работа №5

## Теория

Сверточная нейронная сеть обрабатывает изображение локальными фильтрами. Один фильтр ищет один тип признака, например край или фрагмент формы. После нескольких сверточных слоев сеть получает все более абстрактные признаки. Слои субдискретизации уменьшают пространственный размер карты признаков и снижают число параметров.

Для переноса обучения берется сверточная основа модели, уже обученной на большом наборе изображений. Ее веса можно заморозить и обучать только новый классификатор под свою задачу.

## Что сделано

Код написан на PyTorch и torchvision.

Вариант 13:

- этап 1, MNIST: `4` сверточных слоя, карты признаков `64-128-128-256`, ядро `3x3`, классификатор `512`;
- этап 2, Cats vs Dogs: вход `200x200`, сверточные слои `32-64-64-128`, ядро `3x3`, классификатор `256`;
- этап 3: заморозка сверточной основы предобученной сети и обучение только классификатора, по варианту `70` эпох.

В `main.ipynb` полностью запускается этап MNIST. Для Cats vs Dogs и transfer learning описаны и создаются модели, потому что сам набор Cats vs Dogs в репозитории отсутствует. Когда данные будут добавлены, эти модели можно подключить к обычному `ImageFolder`.

Выбор устройства:

```python
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

## Что получилось

При запуске скачивается MNIST через torchvision, обучается CNN варианта 13 и печатается тестовая точность. Графики сохраняются в `mnist_history.png`.

Полный проверочный запуск ноутбука на `30` эпохах дал:

- устройство: `cuda`;
- MNIST test loss `0.0511`;
- MNIST test accuracy `0.9915`;
- параметры Cats vs Dogs модели: `4_849_281`;
- обучаемые параметры transfer-модели: `131_585`.

В ноутбуке число эпох задается обычной константой в кодовой ячейке. Для полного запуска по заданию используется `30` эпох.

Также скрипт выводит:

- число параметров модели Cats vs Dogs;
- число обучаемых параметров transfer-модели после заморозки основы.

Основной файл работы: `main.ipynb`.
