# Сбор и обработка данных — лабораторные работы ПФУР

Учебный репозиторий по сбору, анализу и подготовке данных для машинного обучения.

## Содержание

- `lab_1` — работа с табличными данными;
- `lab_2` — парсинг и сбор данных с BeautifulSoup и Selenium;
- `lab_3` — эксперименты с CatBoost;
- `lab_4` и `lab_5` — дополнительные задания по анализу данных;
- `lab_7` — датасет и материалы для задачи обнаружения объектов на изображениях.

## Запуск

Каждая лабораторная автономна. Откройте соответствующий `.ipynb` в JupyterLab или Google Colab и выполняйте ячейки сверху вниз. Некоторые задания содержат большие датасеты, поэтому для запуска может потребоваться достаточно места на диске и GPU.
