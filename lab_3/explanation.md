# Лабораторная работа №3

## Теория

Сеть Элмана относится к рекуррентным сетям: на каждом шаге она использует текущий вход и скрытое состояние, полученное на предыдущем шаге. Поэтому такая сеть подходит для динамических образов, где важен порядок значений во времени.

Сеть Хопфилда является ассоциативной памятью. Веса строятся по эталонным бинарным образам, а затем сеть итерационно переводит зашумленный вход к ближайшему устойчивому состоянию.

Сеть Хэмминга решает похожую задачу распознавания статических образов, но делает это через сравнение входа с эталонами. Первый слой вычисляет близость к каждому образу, второй слой с латеральным торможением оставляет наиболее похожий эталон.

## Что сделано

Вариант 13:

- для сети Элмана использована функция `g(k)=sin(2k^2-6k+3)`, интервал `[-0.02, 2.36]`, шаг `0.025`, набор повторов `R=[2,5,6]`;
- основному сигналу `p1(k)=sin(4*pi*k)` соответствует целевой выход `-1`, сигналу `p2(k)=g(k)` соответствует `1`;
- реализована рекуррентная сеть PyTorch: `RNN(1 -> 8, tanh)` и выходной слой `Linear(8 -> 1)` с `tanh`;
- для статических образов взяты цифры `0`, `1`, `4` размером `12x10`;
- реализованы сеть Хопфилда и сеть Хэмминга без сторонних нейросетевых фреймворков;
- проверено распознавание чистого образа, образа с шумом 20% и образа с шумом 30%.

Код выбирает устройство так:

```python
DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

Поэтому при наличии CUDA расчеты идут на GPU, а без CUDA код работает на CPU.
