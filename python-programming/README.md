# Программирование на Python — лабораторные работы ПФУР

Набор учебных заданий по Python: базовый синтаксис, ООП, регулярные выражения, работа с файлами, асинхронность и Telegram-бот.

## Структура

- `first_year/` — лабораторные первого года обучения;
- `second_year/` — задачи по асинхронному программированию, ООП и работе с данными;
- `pyproject.toml` — настройки Ruff (наборы lint-правил и исключение для `__init__.py`).

## Запуск

Работы запускаются отдельно: как Python-скрипты или в Jupyter. Например, из каталога `python-programming/`:

```bash
python first_year/first_lab/1.py
```

Для ноутбуков выберите нужный файл `.ipynb`. Единого приложения или общего файла зависимостей в каталоге нет.
