# Учебные работы — ПФУР, Факультет искусственного интеллекта

Архив лабораторных и курсовых работ бакалавриата Российского университета дружбы
народов (Peoples' Friendship University of Russia). Каждый курс лежит в своей
папке и остаётся самостоятельным: своя README, свои данные, свои ноутбуки.

История коммитов перенесена из отдельных репозиториев, в которых эти работы
велись изначально.

## Курсы

| Папка | Курс | Основное содержание |
| --- | --- | --- |
| [`intro-to-it/`](intro-to-it/) | Введение в ИТ | Основы Python за два семестра, тесты на `pytest` |
| [`python-programming/`](python-programming/) | Программирование на Python | Синтаксис, ООП, регулярные выражения, файлы, асинхронность, Telegram-бот |
| [`git-basics/`](git-basics/) | Git | Практика коммитов, веток и удалённых репозиториев |
| [`java/`](java/) | Java | Maven-проект: очередь, стек, сортировки, модульные тесты |
| [`data-analysis/`](data-analysis/) | Анализ данных | Табличные данные, SQL-подобный анализ, проект по NoSQL |
| [`big-data-analysis/`](big-data-analysis/) | Анализ больших данных | Подготовка и анализ крупных выборок |
| [`data-visualization/`](data-visualization/) | Визуализация данных | Семь лабораторных: графики, статистика, интерактивная визуализация |
| [`data-collection/`](data-collection/) | Сбор и обработка данных | Парсинг на BeautifulSoup и Selenium, CatBoost, детекция объектов |
| [`nosql/`](nosql/) | NoSQL | Нереляционные базы данных в Docker |
| [`neural-networks/`](neural-networks/) | Нейронные сети | Ноутбуки, отчёты и сгенерированные иллюстрации |

## Как запускать

Единой точки входа нет — работы независимы. Откройте нужный `.ipynb`
в JupyterLab или Google Colab и выполняйте ячейки сверху вниз; зависимости
указаны в первых ячейках каждого ноутбука. Для `nosql/` понадобится Docker,
для `java/` — JDK 21 и Maven.
