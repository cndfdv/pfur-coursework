# Учебные работы — ПФУР, Факультет искусственного интеллекта

Архив лабораторных и курсовых работ бакалавриата Российского университета дружбы
народов (Peoples' Friendship University of Russia). Каждый курс лежит в своей
папке и остаётся самостоятельным: свои зависимости, данные и инструкции запуска.

История коммитов перенесена из отдельных репозиториев, в которых эти работы
велись изначально.

| Папка | Курс | Основное содержание |

## Как запускать

Единой точки входа нет — работы независимы. Сначала откройте README нужного
курса или лабораторной. Ноутбуки выполняйте сверху вниз в JupyterLab;
зависимости устанавливайте из `requirements.txt`, `environment.yml` или
по инструкциям конкретной работы.

- [Hadoop и Spark](hadoop/README.md): окружение `hadoop`, запуск ноутбуков и экспорт PDF.
- [ИИ в лингвистике](ai_in_linguist/README.md): Python 3.12, зависимости и локальный корпус текстов.
- [RAG, третий семестр](intro-to-it/third_semestr/README.md): подготовка данных и индексов на `home`, запуск Streamlit или Docker. Большие данные и индексы исключены из Git.
- [Нейронные сети, первый семестр](neural-networks/semestr_1/README.md): ноутбуки, пояснения и готовые отчёты. Работы второго семестра находятся в `neural-networks/semestr_2/`.
- [Информационная безопасность](it_secur/lab_1/README.md): описание Excel-книги и контрольные результаты.
- [NoSQL](nosql/README.md): лабораторные с Docker; [Java](java/README.md): JDK 21 и Maven.
