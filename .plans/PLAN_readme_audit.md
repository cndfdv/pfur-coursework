## Цель и границы

Проверить все 28 README по текущему дереву Git. Исправить неверные пути,
команды и описания; убрать устаревшие или не относящиеся к запуску сведения.
Код, данные, задания и результаты лабораторных не менять. Подозрительные
дубликаты и служебные файлы проверить отдельно; неоднозначные материалы не удалять.

2. Проверить ai_in_linguist, hadoop, it_secur, neural-networks и README

3. Проверить корень, intro-to-it и RAG третьего семестра, а также признаки
   лишних файлов. Владелец: основной агент. Объединить результаты шагов 1–2.
4. Проверить локальные ссылки, упомянутые пути, diff и область изменений.
   Сохранить проверенный результат коммитом и синхронизировать GitHub/home,
   если рабочие папки позволяют безопасное fast-forward обновление.

## Проверка и завершение

Проверка документации по файлам без установки зависимостей и выполнения
тяжёлых лабораторных. E2E и запуск ML не нужны: поведение кода не меняется.
Основной агент проверяет изменения агентов. Сохранять точные ограничения:
не выдавать исторические результаты за новую проверку окружения.
