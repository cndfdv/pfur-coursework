Порядок выполнения работы

Подготовка и разведочный анализ данных (EDA):
Загрузить набор данных в соответствии со своим вариантом.
Произвести очистку данных: идентифицировать и удалить записи с пропущенными (NULL, ? или NaN) значениями.
Вывести схему датафрейма (printSchema()), типы данных столбцов (dtypes) и общую форму набора данных.
Рассчитать основные статистические показатели для числовых признаков при помощи метода summary() или describe().
Предобработка и векторизация признаков:
Выделить из набора данных целевую зависимую переменную (Target) и категориальный признак (Class), указанные в описании варианта.
Для текстовых или категориальных признаков применить StringIndexer для кодирования в числовые метки, а затем преобразовать их с помощью OneHotEncoder (при необходимости).
Использовать VectorAssembler для объединения выбранных входных признаков в единый векторный столбец (features), требуемый алгоритмами Spark ML.
Обучение моделей:
Разбить подготовленный датасет на обучающую (Training) и тестовую (Test) выборки в соотношении 80:20 с фиксированным значением генератора случайных чисел (seed=42).
Поочередно построить и обучить на обучающей выборке следующие модели регрессии:
Множественная линейная регрессия (LinearRegression).
Регрессия на основе дерева решений (DecisionTreeRegressor).
Регрессия на основе случайного леса (RandomForestRegressor).
Регрессия на основе градиентного бустинга деревьев (GBTRegressor).
Оценка качества и сравнение моделей:
Для каждой из четырех обученных моделей сделать предсказания на тестовой выборке при помощи метода transform().
Используя компонент RegressionEvaluator, рассчитать для каждой модели метрики качества:
Среднеквадратическая ошибка (MSE или RMSE).
Коэффициент детерминации (R²).
Составить сводную таблицу метрик для всех моделей.
На основании полученных метрик провести сравнительный анализ, выявить наличие недообучения или переобучения и определить лучшую модель регрессии для исследуемого набора данных.
Определить ключевой числовой признак как числовой признак с наиболее высокой важностью для лучшей модели на основе деревьев решений.
Визуализация результатов:
Построить диаграмму рассеяния (Scatter Plot) для исходного набора данных на плоскости (зависимость целевой переменной от ключевого числового признака) с визуализацией точек данных разными цветами в зависимости от категориального признака.
Отобразить на одном графике линии (или аппроксимирующие кривые) предсказанных значений для каждой из построенных моделей регрессии.
Сгенерировать и визуализировать кривую обучения (Learning Curve) для модели на основе деревьев решений с лучшим показателем коэффициента детерминации, отобразив метрику качества на обучающей и валидационной выборках в зависимости от объема используемых данных.
Оформление отчета:
Оформить отчет в формате ipynb с выполненным кодом, содержащий титульный лист, цель работы, краткие сведения о структуре данных вашего варианта, результаты выполнения каждого пункта (таблицы, графики визуализации) и итоговый вывод с обоснованием выбора лучшей модели.
Все наборы данных берутся из открытого репозитория машинного обучения UCI Machine Learning Repository.
