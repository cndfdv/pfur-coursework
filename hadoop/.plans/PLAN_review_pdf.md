# Проверка лабораторных 3–5 и PDF

READY: yes

Цель: сверить три ноутбука с заданиями, исправить подтверждённые ошибки,
выполнить с чистого ядра и сохранить PDF рядом с каждым ноутбуком.
Colab исключён пользователем. Чужие изменения и исходные данные не менять.

1. Проверка содержания: main.ipynb и task.md в lab_3–lab_5.
   Независимый ML-reviewer проверяет требования, утечки и выводы без записи файлов.
   Исправлять только конкретные ошибки; сохранить короткие студенческие формулировки.
2. Проверка исполнения: последовательно выполнить ноутбуки в окружении hadoop.
   Сверить очистку и ключевые результаты с независимыми расчётами по CSV;
   для регрессии добавить прогноз средним обучающей выборки как ориентир.
   Успех: последовательные номера выполнения, нет ошибок, таблицы и графики сохранены.
3. Экспорт: scripts/export_notebooks.py, main.pdf в трёх каталогах.
   Использовать nbconvert HTML и установленный Chrome, если кириллица и графики
   сохраняются корректно. TeX устанавливать только при необходимости.
   Проверить текст и изображения PDF, отрендерить и просмотреть все страницы.
4. Обновить README и явные зависимости окружения. Записать фактические результаты
   проверки сюда, просмотреть scoped diff и создать локальный checkpoint.

Проверка пользовательского результата: открываемые PDF с полным кодом, таблицами,
графиками и выводами. Отдельные E2E-тесты приложения не нужны.

Риски: вывод Spark может быть слишком широким для страницы; проверка вёрстки
обязательна. Метрики на разных машинах могут немного различаться.

## Результаты

- Независимый ML-reviewer сверил все требования и просмотрел все 8 графиков.
  Исправлены необоснованный вывод о недообучении и правило R² < 0.2;
  уточнены близость RF/GBT, смысл усреднённых прогнозов и граница возраста 60 лет.
- Все три ноутбука выполнены последовательно с чистых ядер в mamba hadoop:
  9 + 10 + 11 = 30 кодовых ячеек, ни одного error output, nbconvert exit 0.
- Независимый pandas-расчёт подтвердил Telco: 7043 строки, 11 пропусков,
  фильтр 3483 строки, все значения pivot. Adult: 32561 → 30162 → 30139 строк,
  совпадают топ-5 стран и возрастные группы; копии adult.data идентичны.
- Lab 5: прогноз средним RMSE 11.9202, R² -0.0001; RF RMSE 10.3680,
  R² 0.2434; GBT 10.3714 / 0.2429. Разрыв RF train/test R² 0.0329.
  Кривая обучения: 5 размеров выборки, конечный validation R² 0.2322.
- Созданы PDF рядом с ноутбуками: 6, 9 и 11 страниц. TeX не потребовался.
  Широкие таблицы разделяются по столбцам с повторением первого столбца,
  все значения сохранены; в PDF опущены только служебные stderr-предупреждения.
- Проверка pypdf/pdfplumber подтвердила полный код всех 30 ячеек в PDF,
  все 8 изображений, кириллицу, отсутствие пустых страниц и текста за границами.
  Проверены примеры узкой/широкой таблицы и обычного текста экспортера;
  py_compile, ruff check и git diff --check прошли.
- README содержит команды запуска и экспорта и источники данных;
  pyarrow явно добавлен в environment.yml (в окружении уже установлен).
- Визуальная проверка всех 26 страниц завершена. Исправлен перенос inline-code
