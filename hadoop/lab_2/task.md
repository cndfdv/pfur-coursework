Вариант 7: Анализ графа социальных связей
Входные данные: Ребра графа в формате user_A,user_B (означает, что они друзья).
Задача 1: Преобразовать данные в симметричный вид: для каждой строки A,B эмитировать (A, B) и (B, A).
Задача 2: Используя groupByKey (или reduceByKey), собрать список друзей для каждого пользователя.
Задача 3 (Оптимизация): С помощью mapValues и flatMapValues найти "друзей друзей" (второй уровень связей), исключив из результата самих друзей и исходного пользователя.

1. Задания выполняются в среде PySpark (локально или в кластере).  
2. Использование DataFrame API не допускается (работа ведется строго на уровне `pyspark.RDD`).  
3. Студент должен самостоятельно сгенерировать тестовые данные (текстовые файлы).  
4. Отчет в формате Jupyter Notebook с выполненным кодом должен содержать Титульный лист с указанием Ф.И.О. студента, группы и варианта.
