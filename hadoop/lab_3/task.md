UDF: Минимум одна пользовательская функция должна быть реализована через стандартный udf, а для числового масштабирования используйте pandas_udf.

Базовый алгоритм выполнения (для всех вариантов)
Необходимо выполнить следующие 6 шагов для своего варианта:

Загрузка и очистка: Загрузить CSV в DataFrame. Обработать пропущенные значения (NULL).
Фильтрация: Отфильтровать данные по сложному условию (используя &, |, isin, like или between).
Агрегация и Pivot: Сгруппировать данные и построить сводную таблицу (pivot) или выполнить множественную агрегацию (agg).
Оконные функции: Применить оконную функцию (row_number, rank, lead или lag) с разбиением на секции (partitionBy).
UDF: Написать Python-функцию для категоризации или преобразования данных и применить её через withColumn.
Join: Создать синтетический DataFrame (справочник) из 5-10 строк и объединить его с основным датасетом.

Вариант 7. Отток клиентов телеком-компании (Telco Customer Churn)
Датасет: WA_Fn-UseC_-Telco-Customer-Churn.csv (доступен на Kaggle)

Столбцы: customerID, gender, SeniorCitizen, Partner, Dependents, tenure (месяцев обслуживания), PhoneService, InternetService, Contract, PaperlessBilling, PaymentMethod, MonthlyCharges, TotalCharges, Churn(ушел/остался).
Очистка: В столбце TotalCharges присутствуют пустые строки вместо чисел. Необходимо привести столбец к числовому типу (DoubleType) и заполнить пропущенные значения (NULL) медианой или средним значением.
Фильтрация: Оставить клиентов, которые обслуживаются дольше 12 месяцев (tenure > 12) И ежемесячный платеж которых превышает 50.0 (MonthlyCharges > 50.0).
Pivot: Сгруппировать данные по типу контракта (Contract), сделать pivot по типу интернета (InternetService — DSL, Fiber optic, No), значения — среднее значение MonthlyCharges.
Окно: Присвоить rank по убыванию MonthlyCharges внутри каждой группы Contract, чтобы определить самых дорогих клиентов в каждом типе контракта.
UDF: Написать пользовательскую функцию, которая категоризирует клиентов по стажу (tenure): "Новичок" (0-12 мес.), "Лояльный" (13-36 мес.), "Ветеран" (37+ мес.).
Join: Создать синтетический справочник PaymentMethod -> Payment_Category (например, "Electronic check" -> "Автоматический", "Mailed check" -> "Ручной", "Bank transfer" -> "Автоматический", "Credit card" -> "Автоматический") и объединить его с основным датасетом.
