⁃ Файл SSTable создается на основе кэша: заполняется кэш, а затем на основе данных в нем создается файл SSTable на файловой системе
 ⁃ При записи на файловую систему использовать структуру SSTAble (HEADER, DATA BLOCKS, SPARSE_INDEX, FOOTER)
 ⁃ Для проверки работы: 1) заполнить кэш 10000 значений, произвести запись на диск. 2) Далее создать новый кэш, который считывает SSTAble и при вызове GET возвращает нужное значение
