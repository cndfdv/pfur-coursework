# Git — лабораторная работа РУДН

Небольшой учебный репозиторий для практики базовых операций Git.

## Содержание

- `hm1.txt` — материал/результат домашней работы.

## Использование

Репозиторий предназначен для практики с коммитами, ветками и удалённым хранилищем. Для начала работы клонируйте его и изучите историю изменений:

```bash
git clone git@github.com:cndfdv/lab_git_pfur.git
git log --oneline
```
